# Grants Event Planners — Multi-Page Website

A responsive multi-page event planning website built with HTML and CSS. Features a sticky navigation bar, CSS Grid card layouts, and media queries for mobile, tablet, and desktop.

## Pages

| Page | Description |
|------|-------------|
| Home | Hero section, service cards, location footer |
| Events | Party event showcase gallery |
| Locations | Recent event destinations |
| Themes | Party theme options (Gatsby, Masquerade, 007) |
| About | Company story and history |
| Contact | Contact form with name, email, and message |

## Features

- **Sticky navigation** with consistent layout across all pages
- **CSS Grid** card layouts (3-column responsive grid)
- **Responsive design** with breakpoints at 768px and 600px
- **Flexbox navbar** with call-to-action button
- **Image-driven cards** for services, themes, and destinations

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, media queries)
